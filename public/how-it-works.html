How It Works

Cerulean is a wrapper around real search providers (currently Brave Search, Serper, and DuckDuckGo). It does not crawl the web itself - that is prohibitively expensive for an indie project. What it adds on top:

Source-type classification

Every result gets tagged with one of 10 categories: news, reference, academic, gov, community, docs, shopping, video, health, ai_slop, other. See the About page for what each category includes. The classification is rule-based - a domain list mapping ~220 well-known sites to categories. Unknown domains default to Other.

AI-likelihood scoring

Each result gets a 0.0-1.0 score estimating the probability the page is AI-generated content. Based on title and snippet only (no destination-page fetch):

  • Domain blocklist (known content farms - auto +0.7)
  • Title patterns (Top 10, Ultimate Guide, Discover)
  • LLM-tell phrases (delve into, navigate the complexities, in today's fast-paced)
  • Em-dash density
  • Absence of dates or named entities

The scoring is a heuristic, not a measurement. It is wrong sometimes. Real page-level AI fraction detection requires fetching destination pages and is slower; that is on the roadmap.

Filtering UI

Three layers, all client-side:

  • Hide AI toggle (default on) filters results scoring 0.7 or higher
  • Source-type chips narrow results to selected categories
  • Intent presets (Learn / Latest / Vibe Check / Shop / Primary Sources) apply pre-built category combos

No personalization

Results do not depend on who you are, where you are, or what you have searched before. Two people running the same query get the same results.

What it does not do

  • Page-level AI fraction estimation (roadmap)
  • Bias scoring on news outlets
  • Original-source vs. aggregator detection
  • User accounts, history, saved searches

About the Highlights chip

The Highlights chip is extractive — it pulls representative sentences from result snippets and shows them as bullets. No language model is involved. Off by default. The intent is triage across sources, not replacement of them. This is the deliberate counterpoint to Google's AI Overview.

Known limitations

  • Video search is rough. The Video category badges YouTube/Vimeo results that happen to appear in normal text search, but Cerulean does not yet call provider-specific video endpoints, so dedicated video queries return thin results.
  • Image search is not implemented. Use Google or DuckDuckGo for images.
  • Brave provider caps results at 20 per query (provider limit). Serper and DDG can return up to 50.

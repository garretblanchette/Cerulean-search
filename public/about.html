About

Cerulean is a small indie search engine. Built in a weekend in February 2026, maintained quietly since.

It is not trying to replace Google. It is trying to demonstrate that ad-free, AI-slop-filtered search can still be useful, and to be the search engine its builder actually wants to use.

This is a hobby. No ads. No profit motive. No data collection beyond what the server logs by default. No accounts.

Built by Garret Blanchette in Palm Springs, California. Code at github.com/garretblanchette/Cerulean-search.
